**О приложении** Складской сканер — офлайн Android-приложение для сотрудника склада Л'Этуаль.
Оно ведёт по заданиям приёмки и размещения, проверяет EAN-13 камерой или ручным
вводом и фиксирует результат только после явного подтверждения. Операционные
данные и фотографии накладных остаются на назначенном устройстве.

Android-прототип для складских операций. Реализован полный сценарий приёмки:

1. выбор назначенной накладной;
2. просмотр товаров и планового количества коробок;
3. офлайн-сканирование EAN-13 камерой или ручной ввод кода на экране сканера;
4. просмотр состава коробки и подтверждение каждой физически отсканированной коробки;
5. выбор стандартной или ввод собственной причины расхождения;
6. завершение приёмки и необязательное фото накладной.

Прогресс, набор уникальных принятых коробок, журнал проверок и итог сохраняются локально.
Повторное сканирование уже принятого EAN-13 не изменяет количество.

## Архитектура

- `app/receiving` — модели, правила приёмки и локальный источник демоданных;
- `app` — экраны операции и навигация;
- `scanner` — изолированный модуль сканирования с `BarcodeScannerContract` и
  `ScannerEngine`; базовый адаптер использует CameraX и bundled ML Kit.

Бизнес-правила не зависят от CameraX или ML Kit. Для Zebra DataWedge или SDK ТСД
достаточно заменить реализацию внутри модуля `scanner`, сохранив публичный контракт.
