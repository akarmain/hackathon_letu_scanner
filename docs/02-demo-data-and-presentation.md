## 2. Сценарий защиты

Подготовить: APK на устройстве, разрешение камеры заранее выдано, питание, распечатанные коды `GEL-004`, `PERF-001` и резервный второй телефон с теми же кодами.

| Время | Действие | Что проговаривает демонстратор |
| ---: | --- | --- |
| 0:00–0:15 | Открыть главный экран | «Это нативное офлайн-рабочее место ТСД: магазин, склад и задания уже доступны без сети». |
| 0:15–0:35 | Приёмка GEL-004 | «Камерой читаем EAN‑13, сверяем с ожидаемой поставкой и локально фиксируем результат». |
| 0:35–0:55 | Размещение GEL-004 | «Товар сразу появляется в приёмке и перемещается в рекомендуемую складскую ячейку». |
| 0:55–1:15 | Пополнение PERF-001 | «Пополнение показывает маршрут со склада на полку магазина». |
| 1:15–1:35 | Открыть остатки и GEL-004 | «Здесь — локальная табличная отчётность: сколько товара и в каких ячейках он лежит». |
| 1:35–2:00 | Показать схему модулей/README | «Сканер отделён контрактом: ML Kit можно заменить на Zebra DataWedge без переработки операций». |

## 3. Визуальные правила для ТСД

- Основной фон светлый; один главный акцентный цвет, зелёный успех, янтарный риск, красный ошибка.
- Статус не передавать только цветом: добавлять иконку и текст.
- Основная кнопка на каждом экране — одна, внизу, высотой 56 dp или больше.
- Показывать код ячейки крупно и моноширинно: `A-01-02`.
- Вместо длинных описаний использовать маршрут: `ПР-01  →  A-01-02`.
- После действия показать недвусмысленный экран успеха, чтобы жюри заметило изменение состояния.

## 4. Риски защиты и быстрые решения

| Риск | Что сделать заранее |
| --- | --- |
| Камера не успевает сфокусироваться на этикетке | Распечатать EAN крупно, проверить освещение, держать лист на расстоянии 15–25 см. |
| Камера не выдала разрешение | Выдать разрешение до демонстрации; оставить обработку отказа в приложении. |
| Основная ветка уже выполнена после репетиции | Нужна кнопка «Восстановить демо-данные» в меню разработчика либо переустановка APK. |
| В сети нет доступа | Не использовать сеть, внешние изображения и облачные API. |
| Жюри спрашивает про промышленный ТСД | Показать `BarcodeScanner` как интерфейс и объяснить замену реализации на адаптер DataWedge. |
